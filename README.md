# Série — muscu niveau expert

Application web mobile de suivi d'entraînement : programmes niveau expert par objectif (hypertrophie, force, powerbuilding, sèche), charges de départ calculées sur la taille et le poids, validation des séries en un tap, chrono de repos, progression automatique et suivi des records.

- Un seul fichier : `index.html`, sans build ni dépendance.
- Les données restent dans le navigateur du téléphone (localStorage).
- Déployé sur Vercel : chaque push sur `main` met le site à jour.

Sur iPhone : ouvrir le site dans Safari, puis Partager → « Sur l'écran d'accueil » pour l'utiliser comme une app.
